# HW3 plain-language pipeline briefing

## Purpose

Read three floor plans with a reproducible classical-first workflow, use two independent VLMs only to adjudicate explicit flags, and connect extraction errors to the centre-of-stiffness calculation.

## Frozen stage sequence

1. Preserve and hash the assignment and course images.
2. Run the specified L07 threshold, morphology, components and shape rules.
3. Read labels twice and enforce one label, one compatible bar.
4. Write the immutable baseline record and audit flags.
5. Fit and archive the random forest without allowing it into the promotion path.
6. Freeze flag crops, questions, order, schema, confidence threshold and independent reference.
7. Run two different VLMs through the same harness and apply the non-regression gate.
8. Continue only from the promoted record into gravity-load reuse, CM, wall stiffness and CR.
9. Reproduce the hand result with a declared OpenSees rigid diaphragm and three unit loads.
10. Check push, turn and superposition; modify walls with mass fixed until CR is at CM within the stated tolerance.
11. Lock the implementation, then run NewPlan and the public found plan with no retuning.
12. Build the report from machine-readable results and run the repository verifier.

## Acceptance philosophy

Every stage has an independent check before the next stage is allowed to consume it. Failed attempts remain in the iteration log; accepted machine-readable inputs are never silently rewritten.
